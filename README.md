## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox script executors for Windows, bundled with a universal loader (xcutorsLoader) that lets you install, manage, and launch multiple executors from a single interface.

### Is XCutors free to use?

The XCutors loader itself is free. However, some bundled executors may have their own licensing or subscription requirements. Please check each executor's documentation for pricing details.

### Which Windows versions are supported?

XCutors supports Windows 10 and Windows 11 (64-bit). Older versions such as Windows 7 or 8.1 are not officially supported and may experience compatibility issues.

### How do I update the executors to the latest version?

Open xcutorsLoader.exe and navigate to the 'Updates' tab. The loader will automatically check for new versions of all installed executors and prompt you to update with a single click.

### Why does my anticomponent software flag the program?

Anticomponent engines commonly flag script executors as potentially unwanted programs (PUPs) because they inject code into other processes. This is a false positive for the tools included in XCutors. You may need to add an exclusion for the XCutors folder in your anticomponent settings.

### Can I use my own custom Lua scripts?

Absolutely. All executors in XCutors support loading and running custom Lua scripts. You can paste scripts directly, load them from local files, or use the built-in script editor to write and save your own.

### Which executor should I choose?

It depends on your needs. Volt is known for speed and stability. Synapse Z offers broad script compatibility. Potassium is lightweight and beginner-friendly. Wave provides advanced features for experienced users. Try each one through the loader to see which fits you best.

### How do I report bugs or request features?

You can open an issue on the GitHub Issues page of this repository. Please include a detailed description of the bug, your Windows version, the executor you were using, and any error messages you received.

### Does XCutors work with Roblox UWP (Microsoft Store) version?

Compatibility depends on the individual executor. Some support the standard Roblox Player while others also support the UWP version. Check the executor-specific documentation included in the package for details.
